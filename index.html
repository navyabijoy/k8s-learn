Kubernetes Handbook

Explain Kubernetes out loud, in plain words. Every chapter starts with a problem, names the idea in one sentence, shows a tiny example you can run, then asks you the questions an interviewer would.

Written for Kubernetes 1.37 (latest stable: 1.37.1)
You know

Basic Linux (users, permissions, processes, systemd, cron) and Docker basics. Kubernetes chapters keep pointing back to those.

You will

Run every example on a local cluster, read real output, and answer interview questions in your own words.

Colours

Blue is a key idea. Green is something to try. Amber is a common mistake. Red can break things. Purple is an interview question.

Print

Any chapter saves cleanly as a PDF from your browser's print dialog. Interview answers are expanded in print.

About the labs

Commands were checked against kubernetes.io for 1.37. The sample chapter's real outputs came from minikube on macOS running Kubernetes v1.35.1. Where output is shown, it was run. Where it was not run, only the command is shown.
